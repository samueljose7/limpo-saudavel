# Limpo & Saudável

Cópia independente personalizada do template Ateliê Auto enviado. HTML, CSS e JavaScript originais preservados, com adaptações de conteúdo e identidade.

## Executar
Requer Node.js 18 ou superior. Sem dependências externas de build.

```sh
npm run dev
npm run build
npm run preview
```

## GitHub e Vercel
Envie o conteúdo desta pasta para um novo repositório. Na Vercel, importe o repositório com preset Other, comando `npm run build` e pasta de saída `dist`. O arquivo vercel.json já configura o build.
